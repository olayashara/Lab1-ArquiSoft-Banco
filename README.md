# Aplicación Fullstack Bancaria - Laboratorio 1

Implementation of a Banking Application with Spring Boot backend and React frontend.

Including integration with GitHub Actions, SonarCloud, and Cloud Deployment.

### Folders Structure
* `banco-backend/`: Main Spring Boot backend application and unit tests.
* `banco-frontend/`: Frontend React application.
* `.github/workflows/`: CI/CD automation pipeline.

### How to install and run locally
Execute:
```shell
cd banco-backend
./mvnw spring-boot:run
